Проект для школы WB L0

git clone https://github.com/MortalisMeow/WBSchool.git

docker-compose up --build

Сервис будет доступен по адресу: http://localhost:8081

Проект реализован на Go по принципам Clean Architecture с разделением на Domain, Internal и Adapters.
Взаимодействие между компонентами построено на интерфейсах, что позволило полностью изолировать логику и покрыть код Unit-тестами с использованием моков. 
Проведен рефакторинг main.go для чистой инициализации зависимостей и внедрен Graceful Shutdown для безопасного завершения работы.

Стек технологий включает PostgreSQL для хранения данных, In-memory кэш для быстрого доступа и Kafka в качестве брокера сообщений. 
Для автоматизации тестирования интегрирована библиотека gofakeit, генерирующая реалистичные заказы.
Вся инфраструктура разворачивается через Docker Compose одной командой.
